# FACE ATTENDANCE

เว็บเช็กชื่อภาษาไทย รองรับ webcam, จัดการนักเรียน/ความยินยอม, ตรวจจับและจับคู่ใบหน้าบนอุปกรณ์, ให้ครูยืนยันก่อนบันทึก, เช็กชื่อสำรอง, dashboard และรายงาน CSV/Excel (.xlsx)/พิมพ์

## เริ่มใช้งานบน Vercel + Supabase

เวอร์ชัน cloud ใช้ Supabase Auth, ตาราง PostgreSQL ที่เปิด RLS และ Edge Function `app-api` ส่วนเว็บเป็น static site บน Vercel กุญแจที่อยู่ใน `runtime-config.js` เป็น publishable key เท่านั้น ห้ามใส่ service role/secret key ในเว็บ

1. เปิด URL ของ Vercel และลงชื่อเข้าใช้ด้วยอีเมล/รหัสผ่านของบัญชีที่ผู้ดูแลเพิ่มให้
2. ก่อนมีผู้ใช้คนแรก ผู้ดูแลสร้างบัญชีได้ที่ Supabase Dashboard → Authentication → Users → Add user แล้วคัดลอก UUID ของบัญชี
3. ใน SQL Editor เพิ่มโปรไฟล์ผู้ดูแลด้วยคำสั่งด้านล่าง โดยแทนค่า 2 จุดด้วยข้อมูลของเจ้าของบัญชี:

   ```sql
   insert into public.users (id, email, display_name, role, active)
   values ('<AUTH_USER_UUID>', '<ADMIN_EMAIL>', 'ผู้ดูแลระบบ', 'admin', true);
   ```

4. หลังตั้งค่าผู้ดูแลคนแรกแล้ว ผู้ดูแลสามารถเพิ่ม/ระงับบัญชีครูได้ที่เมนู **บัญชีผู้ใช้** โดยกำหนดรหัสผ่านชั่วคราวอย่างน้อย 12 ตัวอักษรและส่งให้เจ้าของบัญชีผ่านช่องทางปลอดภัย
5. เปิดเมนู **นักเรียน** เพิ่มข้อมูลและห้องเรียน จากนั้นจัดการความยินยอมก่อนลงทะเบียนใบหน้า
6. หน้า **กล้องและเช็กชื่อ** กดเปิดกล้องและอนุญาตสิทธิ์ กล่องสีเขียวจะติดตามตำแหน่งใบหน้าเมื่อ detector พบหนึ่งใบหน้า

การสร้าง Auth user และ profile แยกเป็นสองขั้นตอน หากสร้าง Auth user แล้วแต่ไม่มีแถวใน `public.users` บัญชีนั้นจะเข้าใช้ไม่ได้ ลบหรือปิดใช้งานบัญชีที่สร้างผิดจาก Supabase Dashboard

## พัฒนาหรือใช้แบบ local

ต้องมี Node.js 24 ขึ้นไป

```powershell
cd outputs
npm install
npm run setup
npm start
```

เปิด `http://localhost:8000` จากนั้นใช้บัญชีผู้ดูแลที่ setup สร้างให้ ระบบ local ใช้ SQLite และ session cookie แบบ HttpOnly/CSRF; เก็บ `.env` และ `data/attendance.sqlite` ในพื้นที่จำกัดสิทธิ์ และสำรองทั้งฐานข้อมูลกับกุญแจเข้ารหัส

## วิธีใช้สำหรับครู

1. เปิดหน้ากล้อง เลือกอุปกรณ์ และกด **เปิดกล้อง**
2. จัดใบหน้าให้อยู่ในวงรีกลางภาพ กรอบจะล้อมใบหน้าที่ตรวจพบและเปลี่ยนสีเมื่อพร้อม ถ้าไม่พบ/พบหลายคน ให้จัดภาพใหม่
3. กด **ตรวจสอบใบหน้าเพื่อเช็กชื่อ** ระบบตรวจภาพและแสดงผู้สมัคร หากข้อมูลคล้ายกัน ระบบจะไม่บันทึกเอง
4. ตรวจชื่อและห้องให้ถูกต้อง แล้วกด **ครูยืนยันและบันทึกเวลา** จึงจะสร้างรายการเข้าเรียน
5. ถ้าตรวจไม่ได้ ให้เปิดหน้า **เช็กชื่อ** แล้วบันทึกสถานะด้วยตนเอง การไม่พบใบหน้าไม่ใช่การขาดเรียน
6. หน้า **ตั้งค่า** ให้ผู้ดูแลตั้งเวลาเริ่ม/สายและ threshold จับคู่; หน้า **รายงาน** ใช้กรองวัน/ห้อง/รหัส ส่งออก CSV หรือ Excel (.xlsx) หรือพิมพ์

## ความยินยอมและข้อมูลใบหน้า

- ขอความยินยอมที่เหมาะสมจากผู้ปกครอง/นักเรียนตามนโยบายโรงเรียนก่อนใช้ข้อมูลชีวมิติ และให้มีทางเลือกเช็กชื่อที่ไม่ใช้ใบหน้า
- กล้องทำงานหลังผู้ใช้กดเปิดเท่านั้น ภาพ/ไฟล์ภาพถูกประมวลผลในเบราว์เซอร์และไม่ส่งไปจัดเก็บ
- ระบบส่งเฉพาะ embedding เพื่อเปรียบเทียบ และเข้ารหัสแม่แบบก่อนบันทึก การจับคู่เป็นเพียงคำแนะนำ ต้องให้ครูยืนยัน
- เพิกถอน consent แล้วล้างแม่แบบใบหน้าผ่านหน้าจัดการนักเรียน
- ควรกำหนดผู้รับผิดชอบ นโยบายอายุเก็บข้อมูล และขั้นตอนสำรอง/ลบข้อมูลให้สอดคล้องกับโรงเรียนและกฎหมายที่ใช้บังคับ

## ตรวจสอบและข้อจำกัด

```powershell
npm test
```

ชุดทดสอบตรวจ syntax, login/role, จัดการบัญชี, ตั้งค่าเวลา/threshold, นักเรียน, consent, เข้ารหัสแม่แบบ, matching, การยืนยันโดยครู, การกันเช็กชื่อซ้ำ, dashboard/report และการจำกัดสิทธิ์ มี mock ตรวจเปิด/ปิด camera stream, กรณีตรวจจับใบหน้า และโครงสร้างไฟล์ Excel และเงื่อนไขหน้าเริ่มตั้งค่าผู้ดูแล โดยไม่ใช้ภาพหรือใบหน้าจริง ไม่ได้แทนการทดสอบกล้องจริงบนอุปกรณ์ของโรงเรียน

กล้องต้องทำงานบน HTTPS หรือ localhost และต้องอนุญาตสิทธิ์กล้องในเบราว์เซอร์ รุ่นนี้ยังไม่รับ RTSP/ONVIF โดยตรง; การเชื่อม CCTV ต้องมี gateway ฝั่ง server และ adapter ที่เชื่อถือได้ก่อน

## โครงสร้างและ deploy

- `index.html`, `app.js`, `dashboard.js` — Dashboard, webcam, กรอบตรวจจับ และ teacher review
- `students.html`, `students-api.js` — ข้อมูลนักเรียน consent และลงทะเบียน
- `users.html`, `users.js` — สร้างและระงับบัญชีครู/ผู้ดูแล (admin only)
- `settings.html`, `settings.js` — ตั้งเวลาเรียน/สายและ threshold การจับคู่ (admin only)
- `attendance.html`, `attendance.js`, `reports.html`, `reports.js` — เช็กชื่อสำรองและรายงาน
- `xlsx-export.js` — สร้างไฟล์รายงาน Excel `.xlsx` ในเบราว์เซอร์
- `face-engine.js`, `camera-adapter.js` — ประมวลผลใบหน้าในเครื่องและชั้นเชื่อมต่อกล้อง
- `server.mjs`, `db.mjs`, `setup.mjs` — local API, SQLite และตั้งค่าเริ่มต้น
- `supabase/schema.sql`, migration files — PostgreSQL/RLS, hardening และ API RPC
- `supabase/functions/app-api/` — Edge Function สำหรับ API บน cloud
- `runtime-config.js` — URL และ publishable key สำหรับเว็บ; ค่าทั้งหมดในไฟล์นี้เป็นข้อมูลสาธารณะ
